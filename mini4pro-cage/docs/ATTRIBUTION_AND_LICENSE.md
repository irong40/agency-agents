## If the Printables files are added later

Before importing any of its geometry:

1. Record the author name, model URL and exact license text.
2. If the license is Creative Commons with **NC**, the derived cage is non-commercial only.
3. If it is **ND** (no derivatives) or Printables' Standard Digital File License, do not modify or redistribute the geometry. Use it only as a measurement reference on your own machine.
4. If it is **SA**, the derived cage must carry the same license.
5. Add a row to this file listing which features were derived from it.
